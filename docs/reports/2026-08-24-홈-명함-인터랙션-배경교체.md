# 홈 명함 인터랙션 + 블라인드 배경 이미지 교체

## 1. 개요

- **날짜** : 2026-08-24
- **대상 파일** : `index.html`, `assets/css/home.css`, `assets/js/home.js` (단독 소유 워커 1명)
- **진행 방식** : Orca 워커 단독 구현. 피그마 렌더 PNG(`home-full.png`, `card-node.png`)를
  node 미니 PNG 디코더로 픽셀 측정해 명함 기하를 확정 → 구현 → 헤드리스 Edge 로 정지·드래그·낙하·재장전 프레임 캡처 검증.
- 기존 홈(블라인드 당김·태그라인·메뉴·플로팅 버튼) 코드는 건드리지 않고 그 위에 명함 레이어만 추가.

## 2. 적용 완료된 변경

### 2-1. 블라인드 안쪽 배경 교체 (`home.css`)
- `:root` 에 `--reveal-img:url('../img/home_배경.png')` 지정. `.reveal` 이 이미 `background-image:var(--reveal-img)` + `cover` 를 참조하므로 CSS 한 줄. 핑크(`--reveal`)는 로딩 전 폴백으로 유지.

### 2-2. 명함 기하 — 피그마 픽셀 측정값 (지시값과 다름, 아래 참고)
| 항목 | 지시값 | 측정값(적용) | 근거 |
|---|---|---|---|
| 표시 크기 | 694×382 (0.536배) | **582×321 (0.45배)** | `card-node.png` 모서리 간 거리 321/585, `home-full.png` 평행 긴 변 간격 321 |
| 회전 | 약 -40° | **-50°** | 긴 변 기울기 49.7°, 짧은 변 40.4° (두 이미지 모두 동일) |
| 중심 | (1273, 649) | **(1270, 190)** | 좌하단 꼭짓점 (1205,515)·좌상단 꼭짓점 (960,307) 역산. x 는 지시값과 일치, y 는 명함 대부분이 블라인드 위쪽에 숨은 구조라 190 |
| 끼임 경계 | 4번째 선 (216) | 동일 | 보이는 영역 y 216~515 |

헤드리스 캡처(`rest.png`)와 `home-full.png` 를 나란히 비교해 위치·각도·클리핑이 육안 일치함을 확인했다.

### 2-3. 마크업 (`index.html`)
`.stage` 안 블라인드 SVG 다음 형제로 추가 (z-순서 : SVG 위, `.content` 아래):
```html
<div class="card-mask" id="cardMask" aria-hidden="true">
  <div class="card no-drag" id="card">
    <img class="card__face card__face--back"  src="assets/img/명함_뒷면.png" …>
    <img class="card__face card__face--front" src="assets/img/명함_앞면.png" …>
  </div>
</div>
```

### 2-4. 스타일 (`home.css`)
- `.card-mask` : `inset:0`, 기본 `clip-path:inset(20vh 0 0 0)`(JS 가 곧 폴리곤으로 교체), `perspective:1400u`, `pointer-events:none`(빈 영역은 블라인드 당김으로 통과).
- `.card` : 582u×321u, `left:979u`, `top:190uy − 160.5u`, `transform:translate(--cx,--cy) rotate(-50deg + --rz) rotateX(--rx)`, `preserve-3d`, `cursor:grab` / `.stage.is-pulling .card{cursor:grabbing}`.
- `.card__face` : `backface-visibility:hidden`, 면마다 `filter:drop-shadow(0 4px 15px rgba(0,0,0,.2))`(부모 filter 는 preserve-3d 를 평탄화하므로 면에), `-webkit-user-drag:none`. 앞면은 `rotateX(180deg)` 로 긴 축 뒤집힘에 대응.

### 2-5. 인터랙션 (`home.js`) — 기존 loop/render 에 상태 추가
- **클리핑** : `render()` 에서 슬랫 3 의 아래 엣지 점열(`botPts`)을 그대로 `clip-path:polygon()` 으로 넘긴다. 당김으로 선이 휘어도 명함은 항상 그 선 밑으로만 보이고, 블라인드 열림(fab)·리사이즈에도 자동 추종.
- **잡기** : `#card pointerdown` → `card.state='drag'`, `tear.index=4`, `press.active=true`, `anim.y=tearY` 로 기존 당김 물리 진입. `.no-drag` 라 스테이지 핸들러는 건너뜀.
- **끌기** : `pointermove` 에 분기 하나 — 명함은 커서 델타를 0.35 lerp 로 따라오며 뒤처짐 × 0.15 만큼 기울고(±14°), 블라인드는 `press.y = tearY + 0.35·max(0,dy)` 로 약하게만 당겨진다(`CARD_GAIN`). 위로는 0.25 저항.
- **놓기** : `release()` → `dropCard()`. `card.y < 13%·H` 면 스프링(`K .08, D .70`) 복귀(오버슈트 6px), 이상이면 낙하. 블라인드는 기존 `REL_K/REL_D` 로 출렁이며 복귀.
- **낙하** : 시간 기반 — 중력 `0.5H/s²` 로 가속 후 종단속도 `0.6H/s` 등속(화면 밖까지 ≈2.0s), 좌우 `0.05W·sin(2πt/1.2)` 살랑임 + 1/4 주기 앞선 `14°·cos` 기울기(0.5s 램프인), `rotateX = 200°/s` 로 긴 축 기준 뒤집혀 0.45~1.35s 구간에 앞면 노출 후 다시 뒷면. 그림자는 면에 붙어 있어 내내 유지.
- **재장전** : `y > 0.85H` 에서 `gone` → 1초 뒤 `y = −0.45H`(마스크 위)에서 같은 스프링으로 스르륵 내려와 끼워진다(오버슈트 25px, 0.75s). 반복 가능. 복귀 중 다시 잡아도 현재 오프셋 기준으로 잡혀 튀지 않는다.
- **감소 모션** : `MOTION = 0.05` 한 상수로 낙하 시간 축·재장전 딜레이를 20배 단축.
- 스타일 쓰기는 `card.state !== 'rest'` 인 동안(+1프레임)만.
