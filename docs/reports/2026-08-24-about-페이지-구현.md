## 2. 적용 완료된 변경

### 구조

- 1920 아트보드 세로 3면(1080 + 1471 + 1080 = **총 3631**)을 `.about__frame` 한 캔버스로 구성, `.about__scroll`(overflow-y:auto)에서 세로 스크롤.
- 모든 좌표·크기·폰트는 피그마 절대값을 `--u`(100vw/1920) 비례로 사용 — 가로 기준 스케일이라 어떤 화면 폭에서도 디자인 비율 유지.
- 메뉴는 스크롤 밖 `.about` 직속으로 두어 스크롤해도 다른 화면과 같은 자리에 항상 표시 (피그마의 1·2면 반복 메뉴는 고정 메뉴 하나로 통합 — 기능 유지 목적의 의도적 변환).
