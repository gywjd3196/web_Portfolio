- **날짜**: 2026-08-24
- **대상 파일**: `index.html`, `assets/css/home.css`, `assets/js/home.js`
- **진행 방식**: 단일 세션 직접 구현 (3개 파일 소규모 수정으로 에이전트 분담 없이 진행)

## 2. 적용 완료된 변경

### 상세 페이지 메뉴바 — Menu, Home, Work, About, Email, Linkedin (6칸)

- **`index.html`**
  - `#workMenu`(Work 화면): 기존 5칸에서 **Home 항목 추가** → Menu · Home · Work · About · Email · Linkedin 순.
    Menu 라벨은 홈과 동일하게 클릭 불가 라벨(`span`)로 통일하고, 홈 복귀 역할은 새 Home 항목이 담당.
  - **About 화면 신설**(`#about` 섹션): 콘텐츠 제작 전이므로 동일한 6칸 메뉴바만 있는 빈 오버레이.
    홈/Work 메뉴의 About 클릭 시 열림.
  - 홈 메뉴(`#menu`)는 기존 5칸(Menu · Work · About · Email · Linkedin) 유지.

### `assets/css/home.css`

- 메뉴 열림 딜레이에 6번째 칸(`nth-child(6)`, .22s) 추가 — 위→아래 순차 등장 유지.
- 닫힘 딜레이를 `nth-child` → `nth-last-child` 기준으로 변경 — 끝에서부터 세므로 5칸(홈)·6칸(상세) 메뉴가 같은 규칙으로 아래→위 순차 퇴장.
- `.about` 오버레이 블록 추가 (`.work`와 동일한 fixed 풀스크린, `z-index:11`).
- Menu 라벨이 더 이상 클릭 대상이 아니므로 `.work .menu__slot--label` cursor 규칙 제거.

### `assets/js/home.js`

- 메뉴 링크 핸들러 단순화: `home` → 전부 닫고 홈, `work` → Work 화면, `about` → About 화면. work-details 오버레이는 어느 이동에서든 닫힘.
- `openAbout()` 추가 (openWork 와 동일 패턴).
- About 메뉴 호버 열림은 기존 `.menu` 공통 바인딩이 자동 적용.
