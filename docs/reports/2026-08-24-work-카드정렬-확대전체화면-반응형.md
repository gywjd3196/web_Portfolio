## 2. 적용 완료된 변경

### 문제 1 — 카드 내부 절대배치 (썸네일 윗단 정렬 + 하단 괘선 간격)

원인: `.project` 내부가 플로우+마진 혼합이라 --u 기반 텍스트 높이(--uy 와 축이 다름)가
세로 압축 화면(uy<u)에서 아래 요소를 밀어냄.

- `.project` — `display:flex` 제거, `height:calc(529 * var(--uy))` 부여 (카드 끝 977 − top 448)
- `.project__title` — `position:absolute; top:0` (피그마 448 = 카드 top), margin-bottom 제거
- `.project__title--tight` 규칙 삭제 (마진 분기 불필요 — 클래스는 HTML 에 잔존, 무해)
- `.project__client` — `top:calc(160 * var(--uy))` (피그마 608 − 448)
- `.project__meta` — `top:calc(205 * var(--uy))` (피그마 653 − 448)
- `.project__thumbwrap` — `top:calc(273 * var(--uy))` (피그마 721 − 448), 높이 256uy 유지

→ 4개 카드가 동일 오프셋을 쓰므로 썸네일 윗단(721) 완전 정렬, 썸네일 하단(977)과
하단 괘선(1008.6) 사이 31.6uy 간격 복원. 상단 괘선(414)~카드(448) 간격 34uy 와 균형.
`.detail .project` 복제 카드도 같은 자식 규칙을 상속하므로 자동으로 동일 배치.

**1920×1080 검산**: 타이틀 448 / 클라 608 / meta 653 / 썸네일 721~977 / 괘선 1008.6 — 피그마 표와 일치
(타이틀·클라·롤·날짜는 기존 `text-box-trim:cap` 으로 캡 기준 y 정렬).

### 문제 2 — is-zoom 확대 시 전체 화면

원인 (둘 다 해당):
1. 베이스 `.detail__pdfarea` 의 `height:calc(948 * var(--uy))` 가 zoom 의 `inset:0` 중
   bottom 을 무효화(over-constrained) → 세로 압축 화면에서 하단 132uy 가량이 뚫림.
2. `.detail.is-open` 의 `translateX(0)` 이 fixed 의 컨테이닝 블록이 됨.

수정:
- `.detail.is-zoom{transform:none;}` — 이미 열린 상태라 슬라이드 전환 불필요, fixed 기준을 뷰포트로 확정
- `.detail.is-zoom .detail__pdfarea` — `width:100vw; height:100vh; min-height:0` 으로 뷰포트 전체 커버 (배경 #E5E5E5 불투명 그대로)
- `.detail.is-zoom .detail__bar{z-index:6;}` — 닫기·축소 버튼이 있는 상단 바가 PDF(z-index:5) 위에 계속 보이게

ESC 복귀(home.js `setZoom(false)`)는 클래스 토글 방식이라 그대로 작동. zoom 시 고해상도
재렌더(`renderW`)도 뷰포트 폭 기준이라 무영향.

### 문제 3 — ≤900px 세로 스택 반응형

`@media (max-width:900px)` 추가 (`prefers-reduced-motion` 블록 앞):

- `.work .work__frame` — `position:relative` + `min-height:100%` 로 플로우 컨테이너화,
  카드 스택만큼 늘어나 기존 `.work{overflow-y:auto}` 로 스크롤.
  `padding-top:448uy` 로 그리드와 같은 첫 카드 시작 y 유지.
- `.work .project` — `position:relative` 1열 스택, 카드 범위에서
  `--u: calc(100vw * 1820 / 1920 / 425)` 재정의 (+ `--uy`, `--cu` 동일 값).
  카드 폭 = 1820 전역 u → 좌우 여백 50u 유지, 내부 425 기준 수치가 카드 폭에 비례 확대.
  문제 1 의 uy 오프셋도 이 스코프에선 u 와 같아 비율 자동 유지. 카드 간격 40 카드u (그리드 거터와 동일 리듬).
- `.work .work__vline` 숨김. 상/하 괘선·Work 라벨·메뉴 유지.
- `.work .work__rule--bottom` — `top:auto; bottom:50uy` 로 스택 아래(프레임 바닥 쪽) 이동.
- `.work__label`·`.menu__word` — `max(70u, 20px)` 최소 폰트 보정 (슬롯 높이도 함께 → 메뉴 슬라이드 애니메이션 유지).
- detail 화면은 이 브레이크포인트에서 무수정 (1445u 카드가 620px 폭에서도 화면 안에 들어옴 — 깨짐 없음 수준).

### 회귀 확인

- 메뉴 z-index:20 호버, 썸네일 크로스페이드 호버, PDF 캐시 로직 무수정.
