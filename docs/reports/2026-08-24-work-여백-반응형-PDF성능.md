### PDF 로딩 성능 (home.js + serve.js)

- **문서 캐시**: url→getDocument promise Map. 닫을 때 destroy 하지 않아 재열기 시 파싱 0초.
- **프리로드**: work 화면이 열리면 4개 PDF 순차 백그라운드 파싱, 카드 pointerenter 시 해당 PDF 우선 시작 (중복 시작 방지).
- **스트리밍**: serve.js 에 HTTP Range(206)/416/Accept-Ranges 구현 + `disableAutoFetch` + 1MB rangeChunkSize — 전체 다운로드 전에 첫 페이지 렌더.
- **첫 화면**: 로딩 인디케이터로 빈 화면 제거, 첫 2페이지는 IntersectionObserver 대기 없이 즉시 렌더.
- **렌더 해상도**: 표시 폭(1303/1920 뷰포트)×DPR 기준으로 낮춰 렌더 시간·메모리 절감, 확대(is-zoom) 시 고해상도 재렌더.
- 검증: `node --check` 통과, 서버 기동 후 curl 로 206/200/suffix/416 응답 실측 확인.
