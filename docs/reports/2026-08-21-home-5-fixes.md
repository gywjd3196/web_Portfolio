## 적용 완료된 변경

### ① 블라인드 선 1px 균일화 (`home.js`, Opus)
- `dpr`을 `build()`에서 캐시, resize마다 갱신. 변형 없는 평평한 엣지만 `snapY`로 하프픽셀 스냅 — dpr 1/1.25/1.5/2/3 모두에서 `y·dpr`이 항상 `.5`에 떨어짐을 수치 검증.
- 당김 중 곡선 구간은 스냅 없이 `geometricPrecision` 유지. 슬랫 면과 선이 동일 좌표를 공유해 면-선 어긋남 없음. `f()` 반올림 2→3자리로 올려 dpr 1.5/3에서 스냅값 보존.

### ⑤ 당김 곡선 스무딩 (`home.js`, Opus)
- `curveCmds(pts, rev, dy)` 단일 빌더로 Catmull-Rom → 큐빅 베지어 변환, `lineD`/`slatD`가 공유 (SEG 14→16).
- 역방향(아래 엣지 우→좌) 순회 시에도 좌표 오차 0으로 정방향과 일치함을 4가지 당김 시나리오로 검증.
- 보너스 수정: 곡선이 화면 좌우 끝에서 잘릴 때 x=0/x=W 점 중복 push로 수직 단차가 생기던 원본 버그 동반 해결.
- 성능: 12슬랫 경로 생성 0.61ms/frame (16.6ms 예산의 ~3.6%) — 60fps 여유.

### ③ TOUCH IT 완전 제거 (양측)
- `index.html` div.touch 블록, `home.css` .touch/.touch__l/.touch__dot 규칙, `home.js` letters/waveAmp/waveTarget/lastMove/물결 루프 전부 삭제. 잔여 참조 grep 0건 (`touch-action:none`은 무관한 CSS 속성).

### ② 이름 굵기 강화 (`home.css`, Sonnet)
- `.name__face` 400→**500** (영문은 Lunchtype25 Medium 실파일 사용). tagline/menu는 400 유지 → 이름-본문 위계 개선.
- 한글(proxima-nova-hangeul)은 킷의 실제 로드 굵기를 세션에서 확인 불가해 임의 보정은 넣지 않음 — **브라우저 육안 확인 후 미세조정 권장** (아래 다음 단계).

### ④ fab 아이콘 교체 (`index.html`+`home.css`, Sonnet)
- 에셋 SVG(원 배경, stroke 2) 인라인 삽입. `.fab`의 `background:var(--ink)` 제거, svg 크기 68×67→154u. hover/active 스케일과 aria-label 유지.

## 후속 수정 (같은 날, 사용자 스크린샷 피드백)

**증상**: 잡아당길 때 곡선이 평면 구간과 만나는 접점마다 작은 고리(선 겹침)가 보임.

**원인**: `curveCmds`의 Catmull-Rom 변환이 균일 간격을 가정 — 곡선 샘플(짧은 간격)과
평면 끝점(매우 긴 간격)이 만나는 접점에서 제어점이 오버슈트해 경로가 잠깐 되돌아감.

**수정**: 접선 가중치를 **현 길이(chord-length) 기반**으로 변경 (`home.js` `curveCmds`).
간격이 균일하면 기존 곡선과 동일하게 수렴하고, 현 길이는 방향 무관이라 슬랫 면(역방향
순회)과 선의 대칭성도 그대로 유지됨. Node 시뮬레이션으로 4가지 당김 시나리오에서
구 코드 최대 2.30px x-역행(=고리) → 신 코드 **0.00px** 확인, `node --check` 통과.

**폰트 조정** (`home.css`): 사용자 지정에 따라 한글 `안효정` = Proxima Nova Hangeul
**Medium(500)**, 영문 `ahn hyojeoung` = Lunchtype25 **Regular(400)** / 사이즈 70u 유지.
(직전 커밋의 "양면 500 통일"을 영문 400 / 한글 500 로 재조정)
