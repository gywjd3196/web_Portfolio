# 오버레이(work·about·detail) 레이아웃 피그마 정렬 + 반응형

## 1. 개요

- **날짜**: 2026-08-24
- **대상 파일**: `assets/css/home.css`, `index.html` (소유권 범위 내에서만 수정 — `home.js`, `serve.js` 무수정)
- **진행 방식**: Orca 디스패치 워커(레이아웃 담당) 단독 작업. 브라우저 실행 없이 코드 검산으로 검증.
- **목표**: work 화면 좌우 240 / 컨텐츠 1440 기준 → 피그마 실제 디자인(좌우 50 / 컨텐츠 1820)으로 교체, 모든 뷰포트에서 같은 여백 비율로 가로 꽉 참.

## 3. 검수/코드 검산 결과

브라우저 없이 좌표 대조 검산 (전부 일치):

- 카드 우측 끝: 50+425=475, 515+425=940, 980+425=1405, **1445+425=1870**
- 구분선 = 거터 중앙: (475+515)/2=**495** ✓, (940+980)/2=**960** ✓, (1405+1445)/2=**1425** ✓
- 괘선 우측 끝: 50+1820=**1870** = 4단 카드 우측 끝 ✓
- 카드 세로: 448(top) + 타이틀57 + 148 = **205**(meta) ✓ / 57+103=**160**(1단 클라이언트) ✓ / 205+49+19=**273**(썸네일) ✓ / 273+256=529 = 카드 h **529** ✓ (448+529=977, vline 하단 976.5 근사 일치)
- 메뉴: 1920−47=**1873** 텍스트 오른쪽 끝 ✓
- detail 괘선: 1445.3+424.7=**1870** ✓, 타이틀 중앙 701.5 ↔ 피그마 703 (1.5px 근사) — low
