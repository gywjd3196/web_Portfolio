# 安曉貞 — Web Portfolio

피그마 `인터랙션 / home` 섹션(1920 × 1080)을 그대로 옮긴 홈 화면입니다.

```
web_Portfolio/
├─ index.html
└─ assets/
   ├─ css/home.css
   ├─ js/home.js
   ├─ fonts/      ← 폰트 파일을 여기에 (아래 참고)
   └─ img/        ← 블라인드 안쪽에 보일 이미지를 여기에
```

## 보는 방법
`index.html` 을 브라우저로 열면 됩니다.
(폰트 파일을 넣은 뒤에는 로컬 서버로 여는 걸 권장 — `file://` 에서는 폰트가 차단될 수 있음)

```bash
npx serve .
```

## 구현된 인터랙션

| 피그마 프레임 | 동작 |
|---|---|
| home-기본 | 커서가 멈춰 있으면 가운데 `TOUCH IT` 이 글자 하나씩 물결처럼 흐름. 마지막 `T` 위의 동그라미는 글자와 한 덩어리로 움직임. 커서를 움직이면 물결이 잦아들고, 0.9초 멈추면 다시 시작 |
| home-한자 호버 | `安曉貞` 에 커서 → `안효정` 으로 한 글자씩(0/55/110ms 간격) 위아래로 넘어가며 교체. 0.34s |
| home-메뉴 호버 | `Menu` 에 커서 → Work · About · Email · Linkedin 이 위에서 아래로 하나씩(0.05s 간격) 내려옴. 영역을 벗어나면 아래→위 순서로 다시 올라감. 0.24s |
| home-커서로 꾹 눌러 잡아당겼을 때 | 화면 아무 곳이나 누른 채 끌면, 누른 지점에서 가장 가까운 가로 경계선이 벌어지고 그 아래(또는 위) 박스들이 커서 쪽으로 끌려가 쌓임. 좌우 끝은 0, 커서 x 지점이 최대인 V 모양. 놓으면 탄력있게 복귀 |
| home-블라인드 인터랙션 | 우측 하단 플로팅 버튼 → 박스 세로가 90 → 45 로 짧아지며(간격 49) 블라인드처럼 열림. 3초 뒤 자동으로 닫힘 |

## 아직 필요한 것

### 1. 폰트  ✅ 정리 완료

딱 두 가지만 씁니다.

| 용도 | 폰트 | 불러오는 방법 |
|---|---|---|
| 영문 · 숫자 | Lunchtype25 Regular Condensed | `assets/fonts/` 로컬 파일 |
| 한글 | Proxima Nova Hangeul | Adobe Fonts 킷 `rgb1grk` (index.html 스크립트) |

CSS 변수 두 개로만 씁니다 — `var(--font-en)`, `var(--font-kr)`.

**한자(安曉貞) 참고** : Proxima Nova Hangeul 에는 한자 글리프가 없어서, 이 세 글자만
`--font-kr` 스택의 다음 순서인 **Noto Sans KR** 로 자동으로 넘어갑니다.
따로 지정할 필요 없이 한 줄(`--font-kr`)로 한글·한자가 다 처리됩니다.
한자도 직접 고른 폰트로 쓰고 싶으면 같은 Adobe 킷의 `sandoll-jebi2` 에 한자가 들어있어
그걸로 바꿀 수 있습니다. (그러면 Google Fonts 링크를 아예 지울 수 있음)

Lunchtype25 는 피그마 렌더링 폭과 맞추려고 자간 -0.025em 을 줬습니다.

### 2. 이미지
블라인드/당김 안쪽에 보일 이미지. 지금은 `#FF13EB` 색상으로 대체돼 있습니다.
`assets/img/` 에 넣고 `home.css` 의 `:root` 에 아래 한 줄만 바꾸면 됩니다.

```css
--reveal-img: url('../img/파일명.jpg');
```

### 3. 링크
Work / About / Email / Linkedin 은 아직 `href="#"` 입니다. 세부 페이지가 생기면 연결 예정.
